# 我的 AI 衣橱

一个手机优先的响应式网页应用（PWA）：拍照录入衣服、自动编号、记录洗涤状态和洗衣历史，
数据可存在本机，也可以通过 Supabase 免费套餐在手机和电脑之间同步。

- 界面语言：简体中文
- 适用设备：安卓手机 / 电脑浏览器
- 技术栈：Vite + React + TypeScript + vite-plugin-pwa（纯前端应用）
- 费用：代码本身免费；Supabase 与静态托管都有免费套餐，**默认不会产生任何费用**

## 一、目录结构

```
my-ai-wardrobe/
├─ index.html                 页面入口
├─ public/                    静态资源（PWA 图标、_redirects）
├─ scripts/generate-icons.mjs 生成 PWA 图标（不依赖第三方库）
├─ supabase/schema.sql        云端建表脚本（阶段六用）
├─ src/
│  ├─ main.tsx                程序入口，注册 Service Worker
│  ├─ App.tsx                 路由与整体框架
│  ├─ types.ts                数据类型与中文文案
│  ├─ styles.css              全部样式（手机优先，宽屏自动适配）
│  ├─ data/                   数据层
│  │  ├─ repository.ts        数据接口定义
│  │  ├─ idb.ts               本机 IndexedDB 读写
│  │  ├─ memoryStore.ts       内存版存储（自动化测试用）
│  │  ├─ localRepository.ts   本机模式实现
│  │  └─ cloudRepository.ts   云端模式实现（Supabase）
│  ├─ lib/                    工具函数（编号、照片压缩、时间格式化、卡通素材库、PWA 安装）
│  ├─ store/wardrobe.tsx      全局状态：当前用本机还是云端
│  ├─ components/             卡片、表单、图片选择器、底部导航等通用组件
│  └─ pages/                  首页 / 我的衣服 / 洗衣记录 / 设置 / 添加 / 详情
```

数据层的核心设计：**页面只认 `WardrobeRepository` 接口**，所以「本机模式」和「云端模式」
对页面来说是同一套代码。切换到云端不需要改任何界面逻辑。

## 二、在电脑上运行（阶段二～五）

需要先安装 [Node.js](https://nodejs.org/)（选 LTS 版本，一路点“下一步”即可）。

```bash
npm install      # 第一次只需执行一次
npm run dev      # 启动开发服务器
```

启动后终端会打印两个地址：

- `http://localhost:5173` —— 这台电脑自己打开
- `http://192.168.x.x:5173` —— **同一个 Wi-Fi 下的手机可以直接打开这个地址**

手机和电脑连同一个 Wi-Fi 时，用手机浏览器访问第二个地址就能真实体验手机版界面，
也可以测试「添加到桌面」。

其它命令：

```bash
npm run build    # 打包成 dist 文件夹（部署用）
npm run preview  # 本地预览打包结果
npm run test     # 运行单元测试
npm run icons    # 重新生成 PWA 图标
```

## 三、功能一览

| 位置 | 功能 |
| --- | --- |
| 首页 | 统计（总数、各分类、待洗）、该洗衣服提醒、最近添加、分类筛选 |
| 我的衣服 | 搜索（编号/名称/颜色/备注）、分类与状态筛选、三种排序、卡片网格 |
| 详情页 | 大图、全部属性、切换洗涤状态、编辑、换照片、删除、这件衣服的洗涤时间线 |
| 洗衣记录 | 按天分组的状态变更时间线、按状态筛选、清空 |
| 设置 | 云端配置与登录、导出/导入备份、添加到桌面、全局默认图片方式、自定义素材库 |

洗涤状态共 5 种：干净 / 待洗 / 洗涤中 / 已晾晒 / 已收纳。
每次状态变化都会记录**变化时间**，标记为「干净」时还会更新**最近洗净时间**。

### 图片显示方式（每件衣服单独设置）

添加或编辑衣服时可以选三种方式：

| 方式 | 说明 |
| --- | --- |
| 📷 真实照片 | 拍照或从相册选图。只要上传了照片就默认用真实照片，图片保持原比例完整显示，不拉伸变形 |
| 🎨 卡通图片 | 内置卡通素材库（7 种上衣 + 7 种外套 + 6 种裤子 × 6 种颜色），也可以上传自己的图片当展示图 |
| 🚫 隐藏图片 | 列表和详情页只显示衣架图标，编号、名称、分类、洗涤状态照常显示 |

- **真实照片**和**卡通展示图**分开存放，互不覆盖；切换方式不会删除任何一张图，随时能切回来。
- 「设置」页可以改**全局默认方式**，只影响以后新添加的衣服，不会动已有衣服的个性化设置。
- 卡通素材全部是 SVG 代码画出来的，任意尺寸都不模糊，也不占安装包体积。

### 编号规则（三个分类独立 + 补最小空缺）

- **上衣、外套、裤子是三个完全独立的序列**，每个都从 001 开始：
  上衣001、上衣002…… / 外套001、外套002…… / 裤子001、裤子002……
- **每次新增都从该分类的 001 开始找当前未被使用的最小正整数编号**：
  - 删掉上衣003 之后，下一件上衣重新拿到 **003**；
  - 删掉上衣002 之后，下一件上衣拿到 **002**；
  - 删掉上衣001 之后，下一件上衣拿到 **001**。
- 删某一类**完全不影响**其它分类的编号。
- 实现上**不维护计数器**，而是每次从「当前实际存在的编号集合」现算最小空缺。
  这样做的好处是不会出现「计数器和数据不同步」导致的跳号——
  刷新页面、关闭重开、重新打包、导入备份、在手机和电脑之间同步，结果都一致。
- 编号的归属以**编号前缀**为准（`上衣xxx` 归上衣序列）。所以万一有旧数据的分类和编号
  对不上（分类是裤子、编号是上衣003），上衣序列也会正确地避开 003，不会出现重复编号。
  设置页的「数据自检」会列出这类记录，但**只报告、不会自动改**。
- 换分类时会在新分类里按同样的规则取号。
- 保存时加了锁，连点两次「保存」不会创建出两件衣服、也不会算重号。
- 首页、列表、详情页、洗衣记录显示的都是同一个 `code` 字段，不会各拼各的。

## 四、隐私与费用

- 本机模式下，所有数据（含照片）只存在这台设备的浏览器数据库里，不上传到任何服务器。
- 云端模式下，数据存在你自己的 Supabase 项目里，其他用户看不到（数据库层已开启行级安全）。
- 前端代码里只放 **anon public 密钥**，它是公开的、只能读到「登录用户自己的数据」；
  数据库密码和 service_role 密钥**永远不要**填进应用或上传到公开仓库。
- 应用不调用任何付费 API，不含广告与内购。
- Supabase 免费套餐：数据库 500MB、文件存储 1GB、每月 5GB 出网流量、5 万月活用户。
  一个人每天存几十张照片，用几年都用不完。超出后需要升级 Pro（19 美元/月），**不升级就只是不能再存，不会额外扣费**。
- 静态托管（Netlify / Vercel / Cloudflare Pages）都有免费额度，个人使用不会产生费用。

## 五、部署到网络（阶段六）

推荐 **Netlify**（拖拽即可，不用装任何东西）：

1. 先在电脑上执行 `npm run build`，得到 `dist` 文件夹。
2. 打开 <https://app.netlify.com/drop>，把 `dist` 文件夹整个拖进去。
3. 等待几秒，会得到一个形如 `https://xxx-yyy-123.netlify.app` 的网址。
4. 手机浏览器打开这个网址即可。页面刷新后仍是同一个应用（`public/_redirects` 已配好路由回退）。

也可以用 Vercel / Cloudflare Pages / GitHub Pages，仓库里已带 `vercel.json`。

> 想用自定义域名（可选）：在托管平台后台添加自己的域名并按提示改 DNS。免费套餐同样支持。

## 六、开启手机与电脑同步（阶段六）

需要用 **Supabase**（免费，数据库 + 登录 + 图片存储一体）。

### 1. 注册并创建项目

1. 打开 <https://supabase.com> → 注册（可用 GitHub 账号一键登录）。
2. 点 `New project`，随便取名字，例如 `my-wardrobe`。
3. 数据库密码自己设置并**记在密码管理器里**（它不会出现在前端，也不需要填进本应用）。
4. 地区选离你近的（如 Northeast Asia / Singapore），等待 2 分钟左右创建完成。

### 2. 建表

左侧 `SQL Editor` → `New query` → 打开本仓库的 `supabase/schema.sql` 全选复制粘贴 → 点右下角 `Run`。

跑完即完成三张表（衣服、洗涤记录、编号计数器）、权限策略和照片存储桶。

### 3. 关闭邮箱验证（省事，可选）

`Authentication` → `Providers` → `Email` → 把 `Confirm email` 关掉，
这样注册完能直接登录，不用先去邮箱点确认链接。

### 4. 拿到两个值

`Project Settings` → `API`：
- `Project URL`：形如 `https://abcdefgh.supabase.co`
- `anon public` 密钥：一长串 `eyJ...`

> ⚠️ 只要 **anon public**。同一页面下方的 `service_role` 密钥是管理员权限，
> 泄露等于别人能读写你的全部数据，**绝对不要复制到本应用，也不要发给任何人**。

### 5. 填进应用

打开应用 → `设置` → `云端同步`：
- 项目地址填 Project URL
- anon public 密钥填 anon key
- 点「保存云端配置」→ 填邮箱密码 → 点「注册新账号」→ 登录。

### 6. 验证同步

手机和电脑用**同一个邮箱账号**登录 → 两边点「立即同步」→ 衣服列表一致即成功。
在手机上新增一件衣服，电脑点「立即同步」后也应该出现。

## 七、在安卓手机上添加到桌面

1. 用 **Chrome** 打开应用网址。
2. 点右上角 `⋮` 菜单 → `添加到主屏幕` / `安装应用`。
3. 确认后桌面会出现「我的衣橱」图标，点开是全屏无地址栏，和普通 App 几乎一样。
4. 拍照录入：`＋ 添加衣服` → `拍照` → 允许相机权限 → 拍完 → `相册` 可补选。
   （如果浏览器询问相机权限，选「允许」。）

## 八、数据备份

`设置` → `数据备份`：

- **导出备份**：下载一个 JSON 文件（含照片）。建议定期存到网盘。
- **导入备份**：选择之前的 JSON 文件即可恢复。导入时按 id 去重，不会覆盖同一条记录。

云端模式下导出的备份也可以拿到另一台电脑上导入。

## 十、常见问题

**Q：手机上打不开电脑显示的 `192.168.x.x` 地址？**
A：确认手机和电脑连的是同一个 Wi-Fi；电脑防火墙需要允许 Node 走「专用网络」。

**Q：PWA 安装按钮没出现？**
A：必须用 `https://` 或 `localhost` 才允许安装；局域网 http 地址可以用浏览器菜单手动添加。

**Q：数据会丢吗？**
A：本机模式的数据跟着浏览器走，清除浏览器数据就会丢，请定期导出备份。
云端模式的数据在 Supabase，随时可以重新登录取回。
